# ArkiRev demo script (3 minutes)

1. Point out the project baseline: **₱1,000,000 allotted**, **₱320,000 actual**, and a 10% contingency.
2. Upload `0000-0009_base_original.png` as the approved plan. ArkiRev confirms the source drawing and unlocks the revised-plan input.
3. Upload `0000-0009_revised_mock.png` as the revision. The comparison runs automatically.
4. Show the annotated plan first, then use the revision brief to explain the impact in plain language.
5. Walk through the detected-change cards: lead trade, planned work window, expected work, and the required site action.
6. Close: “Unread revisions become rework; rework becomes cost and schedule overrun. ArkiRev quantifies both as soon as the revised drawing is received.”
