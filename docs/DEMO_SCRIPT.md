# ArkiRev demo script (3 minutes)

1. Point out the project baseline: **₱1,000,000 allotted**, **₱320,000 actual**, and a 10% contingency.
2. Open **Draw on plan**, draw three rectangles on Rev A, and label them as a new opening, a door move, and a fixture change. If time is tight, click **Use mock changes**.
3. In **Structured changes**, confirm that the reviewer can edit category, severity, trade, and description before impact is calculated.
4. Click **Generate field brief**, then show **Budget planner** for at-risk spend by trade and contingency.
5. Open **Critical path**. Terracotta tasks drive the duration; grey work can run in parallel.
6. Close: “Unread revisions become rework; rework becomes cost and schedule overrun. ArkiRev quantifies both the moment the change is drawn — no BIM and no ERP required.”

## Demo fallback

`Use mock changes` loads `data/samples/mock_analysis.json`. It exercises the complete brief, budget, and schedule UI without drawing, an API, or the production engine branch.
